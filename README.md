# React 2025 - Homework 04 (HW04)

This branch, `HW04`, represents the fourth homework assignment completed as part of the React course in 2025. This assignment is dedicated to solidifying fundamental React concepts, including core Hooks, component state management, event handling, and data rendering.

## 🎯 Learning Objectives of HW04

The primary goals of this homework were to:

* Understand and effectively use the `useState` Hook for managing component-specific state.
* Implement `useEffect` for basic side effects (e.g., logging, simple data fetching, or interacting with the DOM).
* Practice handling user interactions and events (e.g., button clicks, input changes).
* Create reusable and composable components using props.
* Implement conditional rendering to display different UI based on state or conditions.
* Render lists of data efficiently using the `map()` method and unique `key` props.
* Work with basic form elements as controlled components.

## ✨ Key Features & Implemented Tasks

This homework likely includes several distinct tasks or a single comprehensive mini-project, demonstrating the core React concepts mentioned above. Common exercises for this stage of learning include:

* **Interactive Counter Component**: A simple application demonstrating `useState` for numerical state changes and event handling for increment/decrement buttons.
* **Basic Form Handling**: Components for user input (e.g., text fields, checkboxes) with state management to control input values.
* **Dynamic Content Display**: Rendering different UI elements based on a boolean state or a selected option.
* **Passing Data with Props**: Components communicating data down the component tree.


## 🚀 Technologies Used

* **React.js**: Core library for building user interfaces.
* **React Hooks**: Primarily `useState` and basic `useEffect`.
* **JavaScript (ES6+)**: For application logic.
* **CSS**: For styling components.

## 🛠️ Installation and Setup

To run this project locally on your machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/NataliiaVareniuk/React2025.git](https://github.com/NataliiaVareniuk/React2025.git)
    ```
2.  **Navigate into the project directory (and optionally the specific branch):**
    ```bash
    cd React2025
    git checkout HW04 # If you are not already on this branch
    ```
3.  **Install all necessary dependencies:**
    ```bash
    npm install
    # or if you use Yarn:
    # yarn install
    ```

## 🏃 Running the Application

After installing dependencies, you can start the application in development mode:

```bash
npm start
# or
# yarn start
````

The application will automatically open in your browser at: [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000). You can then explore the different tasks implemented in HW04.
